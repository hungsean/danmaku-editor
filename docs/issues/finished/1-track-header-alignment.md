# #1 新增軌道按鈕移到軌道名稱上方，並對齊軌道高度

- 類型：bug
- 狀態：已完成
- 建立：2026-08-14
- 更新：2026-08-14

## 描述

「新增軌道」按鈕要移動到軌道名稱區塊的上方。

另外軌道名稱、刪除按鈕所在的左側欄位，目前跟旁邊實際的軌道列高度、位置沒有對齊，需要讓兩者的高度與位置一致。

## 留言

- 2026-08-14：建立 issue
- 2026-08-14：原本左欄結構是「刻度尺留白 → 新增軌道按鈕列 → 軌道名稱列」，右欄是「刻度尺 → 軌道列」，中間多出來的按鈕列造成左右錯位。把「＋新增軌道」按鈕移進刻度尺留白的角落格（`.tp-ruler-spacer`）取代原本獨立的一列，讓左右兩欄的結構完全對稱（都是「頂部一格 → 軌道列」），軌道名稱與軌道列自然對齊。`extension/content/timeline-panel.ts`、`extension/content/styles.css`。
- 2026-08-14：回饋指出左右兩欄各自用獨立 flex column 分別排版，只是結構對稱、高度未必真的相等（各自的 flex 分配互不知情）。改為單一 CSS Grid：整個 `tp-timeline-wrap` 是一個 grid，第一欄放軌道控制、第二欄放時間軸內容，row 1 固定 22px（新增軌道／刻度尺），其餘每條軌道各自一個 `1fr` row，同一個 row 被左右兩欄共用，因此保證等高。原本的 `trackCol`／`lanesEl` 容器拿掉，新增一個 `trackArea` 覆蓋層（`grid-row: 1 / -1`）取代原本的 `trackCol`，作為播放頭定位與座標換算（拖曳、seek、刻度、彈幕區塊寬度）唯一的參照矩形。`tsc --noEmit`、`pnpm test`、`pnpm build` 皆通過。狀態維持已完成。
